一、准备环境

需要三样东西：

  1. Node.js：建议装 LTS 版本（18 或 20），Hexo 本身是 Node 程序。
  2. Git：用来管理源码和部署到 GitHub。
  3. GitHub 账号：如果仓库名是 <用户名>.github.io，可以直接获得 https://<用户名>.github.io/ 的免费站点。

六、常见坑

  • 仓库名不对：<用户名>.github.io 才是根路径站点；普通仓库会变成 /<仓库名>/ 子路径。
  • 分支不对：GitHub Pages 设置里的分支要和 _config.yml 的 branch 一致。
  • 构建产物误提交：public/、db.json、.deploy_git/ 都是生成物，不要提交到源码仓库。
  • 图片 404：确认 post_asset_folder: true，图片放在与文章同名的文件夹里，路径大小写一致。
  • 中文文件名：URL 会被编码，尽量用英文或拼音命名文章文件；标题仍可以是中文。
