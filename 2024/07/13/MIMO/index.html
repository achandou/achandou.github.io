从 MIMO 到 OFDM：无线通信核心概念梳理

发表于 2024-07-13 分类于 通信技术
从多天线、空间复用到 OFDM 与 FFT，梳理无线通信中几个最容易混淆的核心概念。

MIMO、OFDM、FFT 这三个词经常一起出现，但它们回答的是不同层面的问题：MIMO 解决“用多根天线做什么”，OFDM 解决“怎么把高速数据塞进有限带宽”，FFT 解决“怎么让 OFDM 在工程上算得起”。这篇笔记把它们放在同一条链上，顺带区分通信 MIMO 与雷达 MIMO。

一、MIMO：多天线带来的三种收益

MIMO（Multiple-Input Multiple-Output）指发送端和接收端都使用多根天线。它不是一个单一技术，而是一组利用空间维度的方案：

  1. 空间复用：把数据分成多路，在同一时频资源上并行发送，理论上容量随天线数线性增长。适合信噪比高、散射丰富的场景。
  2. 空间分集：同一份信息经过多条独立衰落路径发送，接收端合并，降低深衰落导致的误码。适合可靠性优先的场景。
  3. 波束成形：通过调整各天线相位，把能量集中到某个方向，提高接收功率、抑制干扰。毫米波和 5G 大规模天线尤其依赖它。

Wi-Fi（802.11n/ac/ax）、4G LTE、5G 都使用了 MIMO 的某种组合。实际能拿到多少增益，取决于信道相关性、天线间距、终端体积和导频开销——天线越多并不自动等于容量越大。

雷达 MIMO 是另一件事。 通信 MIMO 主要追求容量和可靠性；雷达 MIMO 通过发射正交波形、接收端分离，形成“虚拟阵列”，用较少的物理通道获得更高的角度分辨率和波形分集。两者共享多天线思想，但优化目标不同，不能直接套用。

二、OFDM：把宽带拆成很多窄带

OFDM（Orthogonal Frequency Division Multiplexing，正交频分复用）把高速数据分散到大量相互正交的子载波上，每个子载波只承载较低速率的数据。

  • “正交”意味着子载波在频域上重叠，但在一个符号周期内的积分互不干扰，因此不需要像传统 FDM 那样留保护带，频谱利用率更高。
  • 为了对抗多径，OFDM 会在每个符号前加循环前缀（CP）：只要 CP 长度大于信道最大时延扩展，符号间干扰就能被吸收。
  • 优点：频谱效率高、均衡简单（每个子载波只需一个复数系数）、适合宽带高速传输。
  • 缺点：峰均功率比（PAPR）高，对功放线性度要求高；对载波频偏和相位噪声敏感；CP 带来额外开销；突发长度和时延也比单载波方案大。

三、FFT：让 OFDM 从公式变成电路

OFDM 的调制和解调本质上是一对 DFT/IDFT。直接算 N 点 DFT 需要 $O(N^2)$ 次复数运算；FFT 利用旋转因子的对称性和周期性，把复杂度降到 $O(N\log N)$。

以 $N=1024$ 为例，DFT 约需一百万次量级的复数乘法，FFT 只需一万次量级。正是这个数量级的差距，让 OFDM 在 1990 年代之后从论文走进 Wi-Fi、LTE、5G 和数字广播。

四、把它们串起来

一条典型的下行链路可以粗略写成：

接收端反向执行：去 CP → FFT → 信道估计与均衡 → MIMO 检测 → 解调 → 译码。

  • MIMO 决定“空间上能并行几层”；
  • OFDM 决定“频率上怎么分块、怎么对抗多径”；
  • FFT 决定“这些运算能不能在芯片上实时完成”。

小结

概念 解决的问题 关键代价
MIMO 利用空间维度提升容量/可靠性 信道相关性、导频与算力开销
OFDM 在宽带多径信道中高效传输 PAPR、频偏敏感、CP 开销
FFT 让 OFDM 的 DFT 运算可工程化 定点误差、存储与调度复杂度

把这三个概念分开看，再放回同一条链路里，很多“名词解释”才会变成可以推导、可以取舍的工程判断。
